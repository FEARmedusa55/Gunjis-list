Paste your list

Separate fields with | , a tab, or a comma. Order doesn't matter — URLs and the score are detected automatically, and anything left over becomes the name. Missing fields are fine. Re-pasting a name that already exists updates it instead of duplicating.

Share & backup

Sending it to someone? Use the button below — it writes a new .html file with your list baked inside. They just open it. Sending index.html itself won't work: your packs live in your browser's storage, not in that file, so all anyone else sees is the starter examples.

Putting it on a website? This build is read-only — visitors can browse, search and open every link, but there are no editing controls at all. Upload the index.html it gives you. To change the list later, either upload a new one, or drop a data.json beside it and the page will use that instead.

For your own backups, .json is smaller and is what you'd re-import here.

Auto-fill icons & versions

Pulls each pack's icon, Minecraft version and a one-line summary so you don't have to type them. Existing values are never overwritten.

No setup needed. Packs with a CurseForge URL are looked up through CFWidget (a free CurseForge mirror) using the exact slug in that URL, so the icon and version come straight from CurseForge. Anything without a CF URL falls back to a Modrinth search by name.

Advanced: official CurseForge API key (rarely works)
You almost certainly don't need this — CFWidget already covers CurseForge without a key.

Keys generated at console.curseforge.com are refused by the /v1/mods endpoints with a 403 unless CurseForge has approved an application for you; their docs direct third-party services to apply separately. A perfectly valid, correctly formatted key will still fail this test. Nothing breaks if it does — auto-fill just uses CFWidget.
